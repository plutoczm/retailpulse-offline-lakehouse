# 参考说明

本项目为个人原创电商零售离线湖仓项目，业务主题、目录结构、数据模型、代码、README 和文档均围绕 RetailPulse 独立设计。

项目设计过程中参考过公开数据工程学习资料和开源项目的通用架构思想，例如：

- 离线数仓分层思想：ODS、DWD、DIM、DWS、ADS。
- Spark 批处理、Spark SQL、DataFrame API 的通用实践。
- Parquet、分区、broadcast join、cache/persist、小文件治理等常见优化方法。
- Docker Compose 管理本地开发组件的通用方式。
- 数据质量检查和指标口径文档化的通用工程习惯。

本项目不复制外部仓库代码、README、项目名称或业务模型。
